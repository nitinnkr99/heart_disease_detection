a project made by using data science technologies like Scikit, matplotlib, NumPy, Pandas etc and streamlit is used to create a basic web app

#HOW TO RUN THIS PROJECT ?#

* firstly clone the repo in a folder on your local system
* then create a virtual env and actiavte it and install all the necessary packages like numpy,pandas,streamlit,matplotlib,joblib,seaborn,scikit-learn 
* now you need to run this command "streamlit run app.py"
* the webapp will start running on your local machine in the browser
